## Почему выбрана такая структура

- **Словарь** используется для счётчика слов и сумм по категориям, потому что это пара «ключ-значение». Для частот ключ — само слово, а значение — сколько раз оно встретилось.
- **Множества** идеально подходят для общих и уникальных тем, потому что они автоматически убирают повторы, а операции пересечения (`&`) и объединения (`|`) решают задачу в одну строку.
- **Кортеж** нужен, чтобы хранить пару (title, hours) как единое целое. В отличие от списка, кортеж нельзя случайно изменить, он защищён от записи.

## Распаковка кортежа и словарь

В функции `record_and_tuple` я делаю `title, hours = pair`. Это распаковка: значения из кортежа по очереди попадают в переменные. Со словарём так тоже можно делать: `for key, value in dict.items()` работает по тому же принципу. А вот саму запись удобнее хранить в словаре, потому что у неё есть именованные поля (`title`, `hours`, `completed`), и к ним можно обращаться по имени, а не по индексу.

## Что я поняла

- Словари не хранят порядок. Чтобы вывести их в алфавитном порядке, нужно `sorted()`.
- `set()` создаёт пустое множество, а `{}` — пустой словарь. Это разные вещи.
- Метод `.get()` удобен для счётчиков: он возвращает значение, а если ключа нет — ноль.
