# Лабораторная 9

Сделала вариант 8, где отрицательные числа надо уменьшить на 2.

В файле table.py лежат все функции: row_sums считает суммы строк, column_sums - суммы столбцов. diagonal_pattern делает узор из 0, 1 и 2. transform меняет матрицу для моего варианта.

В main.py я ввожу размеры матрицы, потом сами числа. Программа выводит суммы строк и столбцов, узор и новую матрицу. Если ввести не то количество чисел, выведет ошибку.

В test_table.py проверки через assert. Я проверила суммы, узор, свой вариант и то, что исходная матрица не меняется. Все проверки прошли.

Кратко, что поняла:
Матрица это список списков. Если умножать список на число, то строки будут одинаковыми и меняться вместе, поэтому строки надо создавать в цикле. В transform я делаю новую матрицу, поэтому старая не портится.
