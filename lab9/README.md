## Проверки

Суммы строк и столбцов:
- [[1, 2, 3], [4, 5, 6]] -> строки [6, 15], столбцы [5, 7, 9]
- [[7]] -> [7] и [7]
- Пустая матрица -> []

Узор:
- size=1 -> [[0]]
- size=3 -> [[0, 1, 1], [2, 0, 1], [2, 2, 0]]

Вариант 8:
- [[-2, 0, 3], [4, -5, 6]] -> [[-4, 0, 3], [4, -7, 6]]

Исходная матрица не меняется.

## Что я поняла

- Матрица это просто список списков. `matrix[i][j]` значит строка i, столбец j.
- Если написать `[[0] * cols] * rows`, то все строки будут одинаковые, и если поменять одну, поменяются все. Лучше делать циклом.
- Если сделать `matrix.copy()`, то скопируется только внешний список. Внутренние останутся общими. Поэтому в `transform` я создаю новую матрицу и новые строки для неё.
