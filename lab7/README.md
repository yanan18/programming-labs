## Файлы

- functions.py — сами функции
- main.py — запуск программы и ввод данных
- test_functions.py — автоматические проверки через assert

## Как запустить

1. Запустить программу: `python main.py` (ввод и вывод).
2. Запустить проверки: `python test_functions.py` (если ошибок нет, выведет сообщения об успехе).

## Проверки (через assert)

Базовые из задания:
- sum_digits(0) = 0
- sum_digits(507) = 12
- sum_digits(-507) = 12
- average([]) = None
- average([2, 4, 6]) = 4
- normalize_text("  ПРИВЕТ   Мир ") = "привет мир"
- normalize_text("   ") = ""

Мои проверки (Вариант 8):
- select_numbers([-5, 0, 2, 5], 2) = [0, 2]
- select_numbers([], 2) = []
- select_numbers([3, -3, 5, -5], 3) = [3, -3]
- Проверка, что исходный список не меняется после вызова функции.

## Что я поняла

- Функция — это блок кода, у которого есть имя. В скобках указываются параметры. Результат возвращается через `return`.
- Внутри функций я не использую `input` и `print` (кроме `main.py`). Функция должна только принимать данные и возвращать результат. Это позволяет использовать её в разных местах и легко проверять.
- `return` возвращает значение и завершает функцию. А `print` просто показывает текст на экране и ничего не возвращает.
- Переменные внутри функции — локальные. Они существуют только пока работает функция.
- `assert` нужен для проверки. Если условие верное — ничего не происходит. Если ложное — вылетает ошибка. При оптимизированном запуске Python их можно отключить, но для проверки они очень удобны.
