## Что я поняла

- `for` использую, когда знаю точное число итераций (`range`). `while` — когда заранее неизвестно, сколько раз выполнять (например, пока не введут правильное число).
- `range(a, b)` не включает `b`, поэтому для вывода до `b` включительно я пишу `range(a, b + 1)`.
- Накопитель (`total += number`) и счётчик (`count += 1`) нужно заводить **до** цикла и обнулять, иначе они не будут работать.
- Если инициализировать максимум нулём, то для всех отрицательных чисел максимум определится неверно, поэтому нужно брать первое введённое число.
- Цикл `while` завершится, когда изменится условие, либо при срабатывании `break`.
