# Лабораторная работа 5

Вариант 8. Слова, содержащие ровно одну букву «а».

## Файлы

- normalize.py — нормализация текста
- palindrome.py — проверка палиндрома через срез
- replace.py — замена двоеточий на дефисы
- variant.py — вариант 8
- palindrome_loop.py — проверка палиндрома циклом (доп.)

## Проверки

normalize.py
- "  один   два " → "один два", слов 2
- пустая строка → длина 0, слов 0

palindrome.py
- "А роза упала на лапу Азора" → Палиндром
- "а" → Палиндром
- " " → Нет текста
- "Python" → Не палиндром

replace.py
- "a:b:c" → "a-b-c", замен 3
- "abc" → "abc", замен 0

variant.py
- "Анна, армия! Я читаю. Книга, край, рама." 
- Подходящие: армия, читаю, книга, край. Количество: 4.
- Пустая строка → Нет совпадений
- "!!!" → Нет совпадений

palindrome_loop.py
- Проверила на тех же примерах, что и palindrome.py. Результаты совпали.

## Что я поняла

- Строки в Python неизменяемы. Методы `.lower()`, `.strip()`, `.replace()` не меняют исходную строку, а возвращают новую.
- Метод `.split()` без аргументов разбивает по любым пробельным символам и сам убирает пустые элементы.
- Срез `[::-1]` возвращает строку в обратном порядке. А через цикл можно пройти только половину и сравнить символы с концов.
- Слово и подстрока — разные вещи. Слово выделяется через `.split()`, подстрока может быть частью слова.
- Прежде чем писать код, нужно чётко решить, как обрабатывать знаки препинания, регистр и пробелы.
