# Лабораторная работа 6

Вариант 8. Числа от 10 до 20 включительно.

## Файлы

- statistics.py — статистика набора чисел
- transform.py — замена отрицательных модулями
- positions.py — индексы максимума
- variant.py — вариант 8
- remove_duplicates.py — удаление повторов (доп.)

## Проверки

statistics.py
- -2 0 5 3 → количество 4, сумма 6, минимум -2, максимум 5, среднее 1.50
- 8 → количество 1, сумма 8, минимум 8, максимум 8, среднее 8.00
- пустой ввод → "Нет данных"

transform.py
- -2 0 5 -2 → новый [2, 0, 5, 2], исходный [-2, 0, 5, -2]
- пустой ввод → []

positions.py
- 7 7 → [0, 1]
- -3 -1 -2 → [1]

variant.py (контрольный набор -8 -3 0 6 6 1)
- Выборка: [], количество: 0, сумма: 0.

Мой набор для проверки: 5 12 18 25
- Выборка: [12, 18], количество: 2, сумма: 30.

remove_duplicates.py
- 3, 1, 3, 2, 1 → [3, 1, 2]

## Что я поняла

- `append()` добавляет один элемент в конец списка. Можно было бы заменить на присваивание по индексу (`items[i] = value`), но длина списка растёт по ходу, и индексы нужно было бы вести вручную. `append` проще.
- `sorted()` создаёт новый отсортированный список, а `sort()` сортирует на месте и возвращает None. В задании просили сохранить исходный порядок, поэтому я использовала `sorted()`.
- Исходный список не меняется, если я создаю новый список и наполняю его отфильтрованными значениями. Это видно на примере transform.py.
