# Итоговый проект (Лабораторная 12)

Автор: Никонова Яна, УБ-64. Вариант 8.

Тема: План туристических маршрутов (длина в км).
Язык: Python 3.

Как запустить: `python main.py`.
Как запустить тесты: `python test_logic.py` и `python test_storage.py`.

Данные хранятся в `data.json`. Программа предлагает меню из 8 пунктов: показать, добавить, найти, изменить статус, удалить, показать статистику, сохранить и выйти.

Я проверила разные сценарии. Если файла нет, программа пишет пустой список. Если ввести пустое название, она просит ввести заново. Статистика считает общую сумму километров и суммы по категориям.

Все тесты в файлах с `assert` проходят успешно.
