# Лабораторная 10

Сделала вариант 8: надо найти сумму элементов первой строки.

В files_lab.py написала функцию read_matrix, которая открывает файл и проверяет, что там всё правильно: сначала два числа (размер), потом сами строки с числами. Если что-то не так, выдает ошибку. Еще там функция selected_sum, которая считает сумму первой строки для моего варианта.

В main.py сделала функцию read_positive_integer (спрашивает число, пока не введут правильное). Потом она читает matrix.txt, считает суммы строк и столбцов (функции из 9 лабы), и записывает всё в report.txt. Если файла нет или он битый, программа пишет ошибку и не трогает старый report.txt.

Файл matrix.txt я создала сама:
2 3
1 -2 3
4 0 -6

Сумма первой строки: 1 + (-2) + 3 = 2. Программа выдала 2, значит всё верно.

Проверки в test_files.py создают временные файлы и проверяют, что чтение работает и что ошибки ловятся. Все проверки прошли.

Поняла, что файл надо открывать с encoding="utf-8", иначе русские буквы сломаются. И что ошибки лучше ловить через try/except, чтобы программа не вылетала.
